# FastAPI + Docker + Poetry

Este repositório é autocontido e foi preparado para rodar uma aplicação FastAPI estruturada e isolada em um ambiente virtual gerenciado pelo Poetry dentro de um container Docker.

## 🚀 Pré-requisitos
* **Docker**
* **Docker Compose**

## 🛠️ Como Executar
1. Clone o repositório.
2. Execute `docker-compose up --build -d` para subir a aplicação.
3. Acesse `http://localhost:8000` ou `http://localhost:8000/docs`.
4. Execute `docker-compose down` para parar os containers.
